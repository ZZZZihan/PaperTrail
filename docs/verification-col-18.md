## 隔离浏览器故障与问答恢复

命令：`uv run --locked python scripts/browser_fixture.py`。它使用独立临时 PostgreSQL、独立论文库和合成三页 PDF，端口 8001，固定模型名 `OFFLINE-UI-FIXTURE-NOT-A-REAL-MODEL`。所有模型 transport 强制为 `httpx2.MockTransport`，没有真实模型网络请求；不会借用用户凭据、预算或真实论文库。退出自动清理临时数据。

浏览器实际上传合成 PDF、逐题提交中文问题并观察终态：

| 浏览器输入 | 结果 | 关键观察 |
| --- | --- | --- |
| 正常 | answered | 回答明确标为离线测试；点击引用从第 1 页跳到第 3 页，提取文字高亮 Omega 片段 |
| 超时 | failed / model_timeout | 显示超时、保留原题、可主动重试，没有答案 |
| 失败 | failed / model_failure | 显示服务拒绝请求及下一步，没有上游原始错误正文 |
| 无效引用 | failed / invalid_citation | 引用不在当前集合，拒绝展示答案 |
| 证据不足 | insufficient_evidence | 限定“当前已检索证据”，不宣称整篇不存在信息 |

- 运行中原数据库 session 丢失后旧应用仍可执行问答：接受问题及每次模型调用前检查原 guard，失效后拒绝并要求重启应用，不重新取得资格；历史/原文仍可读。独立临时库回归证明第一调用后断线时不会发出第二调用。
- 最终账本快照读取失败导致终态未保存：隔离快照异常，并补安全终态写入；不可恢复的数据库故障由启动/5 分钟过期恢复处理。
- 非有限配置、NUL、未配对 Unicode 字符进入 JSONB：配置、请求及模型输出校验，保留已知用量但拒绝不安全结果。

## 已知限制与人工试用

- BM25 配合查询转换是当前可复现起点，真实样例检索比较尚未完成，不能声称已优于向量检索。
- 每题独立，不使用上一轮对话；提问应写明对象。扫描件、复杂图表、公式和跨页语义可能缺证据。
- 程序只能证明引用存在且归属正确；同一模型的独立支持检查仍可能误判，必须对照原文核对限定条件和数字。
- 本地单用户、单进程，问题串行。没有后台队列的跨进程续跑；中断后保留记录并由用户主动重试。
- 成本按配置单价估算，未知用量保留预留额，不等于供应商账单；不能对任意计费规则承诺严格上限。
- 浏览器静态资源更新后应刷新页面。生产服务稳定试用使用 `make serve`，避免开发自动重载中断问答。
- 未进行公网部署、自动找论文、多篇比较、Agent 循环、多用户；未完成用户产品效果与学习验收。
