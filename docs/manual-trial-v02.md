## 打开已保存内容

旧简介没有新来源标签或覆盖成绩时，页面会明确说明。主动“补全为研读卡”、新问题或失败重试会调用模型，应先核对同一账本的实际余量。当前 Goal 的临时不限量窗口已结束，同账本累计394/394，试读请优先使用已保存内容；刷新、重启和换模型不重置历史；本清单不要求为了核对而反复生成。

## 阅读与核对

1. 读术语与研究问题。用自己的话写出“论文在什么场景遇到什么困难”，标出仍不明白的一个词或一句话。
2. 读方法部分。分别说出输入、关键过程与输出，再找出一个必要设置条件；若简介没有说明，就直接记录缺失，不根据引文替简介补分。
3. 在已有问答历史中查看新 react-03。检查“部分回答”和未覆盖要点是否容易理解，并区分“正文已经写出的有据事实”与“仍缺少的条件”。最新回答已补齐冻结模型和人工轨迹条件；上一条部分回答仍保留，可对照比较，不能覆盖旧失败。
4. 点击一处引用，对照 PDF 的实际物理页和前后文。判断原文是否支持正文的所有细节、数字和适用范围，记录核对花费的大致时间。
5. 阅读已保存研读卡时，区分论文陈述、作者解释和可选教学示意/系统推断；确认没有把假设示例或系统推导当作论文实验。当前ReAct v10新卡已有8/8本项支持和5/5内容覆盖的独立AI核对；这不代替你判断易懂程度或确认原文。Reflexion等历史卡仍可能有已知支持缺口，具体以验证记录为准。
6. 刷新页面，再打开同一简介和问答，确认保存内容及引用可继续查看。重启的工程证据另记，本清单无需中断正在运行的模型任务。
